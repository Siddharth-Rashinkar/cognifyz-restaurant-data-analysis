# 🍽️ Cognifyz Restaurant Data Analysis

## 📌 Project Overview

This project was completed as part of the Data Analysis Internship at Cognifyz Technologies.

The objective was to analyze restaurant data, uncover business insights, and create an interactive Power BI dashboard for data visualization.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Power BI

---

## 📊 Level 1 Tasks

### Task 1: Top Cuisines

* Identified the most common cuisines.
* Calculated cuisine percentages.

### Task 2: City Analysis

* Determined cities with the highest number of restaurants.
* Analyzed city-wise restaurant distribution.

### Task 3: Price Range Distribution

* Analyzed restaurant distribution across price categories.

### Task 4: Online Delivery

* Examined online delivery availability.
* Compared ratings of restaurants with and without delivery.

### Task 5: Restaurant Ratings

* Analyzed rating distribution and voting patterns.

---

## 📈 Level 2 Tasks

### Task 1: Cuisine Combination

* Identified common cuisine combinations.
* Analyzed ratings for different combinations.

### Task 2: Geographic Analysis

* Explored restaurant locations using latitude and longitude.
* Visualized geographical distribution.

### Task 3: Restaurant Chains

* Identified major restaurant chains.
* Compared popularity, ratings, and customer engagement.

---

## 📊 Power BI Dashboard

The dashboard includes:

* KPI Cards
* Top 10 Cuisines
* Top 10 Cities
* Online Delivery Distribution
* Price Range Distribution
* Geographic Restaurant Distribution
* Average Rating by Price Range
* Top Restaurant Chains
